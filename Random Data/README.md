# Dane źródłowe aplikacji

Ten folder służy do przechowywania i porządkowania danych, z których później zostanie zbudowana baza danych **całej aplikacji**. Mimo nazwy „Random Data” nie jest to folder na przypadkowe pliki ani wyłącznie dane testowe.

Każdy zbiór powinien mieć własny podfolder, opis zawartości, źródła i informacje o wersji oraz ograniczeniach. Zachowujemy materiały źródłowe obok danych przygotowanych do przyszłego importu. Schemat bazy i proces importu zostaną opracowane później.

## Dostępne zbiory

- [MRE](MRE/README.md) — 24 amerykańskie menu rocznika 2026, skład produktów oraz wartości odżywcze; tabele, JSON i dokumentacja źródeł.

[ARPOL WZ 1 i WZ 4 WEGE](ARPOL_WZ_2026-10-11/README.md): wykaz składników, 20 kart wariantów, nowe smoothie/napoje, instrukcje proszków, oryginalne PDF-y i poprawiony prompt. Karty produktów są oddzielone od niepotwierdzonych powiązań z racją; zbiór nie jest kompletnym katalogiem official.
