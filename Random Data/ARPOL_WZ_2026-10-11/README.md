## Ograniczenia i następne dane

- Największe nowe pozyskania: smoothie 50 g, herbata 15 g z PDF, osobne malinowy i pomarańczowy izotoniki. Dane waniliowej/wiśniowej czekolady są tropami handlowymi.
- Dla WZ 1 / WZ 4 nadal potrzeba etykiet lub dokumentu dostawcy wiążącego konkretne produkty i smaki z zestawem. Sam URL sklepu lub zgodna masa nie wystarcza.
- Kawa, cukier, cukierki, guma, sól i pieprz: potrzebne nazwy, producenci, warianty, masy sztuki i wartości. Kawa naturalna nie jest automatycznie rozpuszczalną; instrukcja wymaga ustalenia formy.
- Kisiel: zachowano 1644 kJ / 493 kcal i granice B/T. Nie poprawiono 493 na 393 i nie zamieniono granic na zera.
- Izotoniki: opublikowane 238 kcal / W44 g / B0 / T0 pozostają źródłowe, z flagą rozbieżności. Wymagane wyjaśnienie przed publikacją official.
- Suchary PDF i HTML mają takie same makra, lecz inny tłuszcz i skład. Są oddzielnymi wersjami kandydata.
- Czekolada wiśniowa: oferta zawiera też nazwę waniliową. Nie uznano jej za potwierdzoną kartę producenta.
- Brak wersji i numeru partii: data odczytu nie jest rocznikiem racji. Sklepowa data trwałości nie identyfikuje zakupionego zestawu.
- Różne składy opisów handlowych (np. kisiel zamiast smoothie w WZ 4) nie są łączone. Punktem wyjścia jest karta ARPOL odczytana tego dnia.
- Dla danych amerykańskich zachowano istniejący [MRE 2026](../MRE/README.md); porcje COMRAD i alternatywy wymagają jego własnych reguł. Nie użyto MRE do uzupełnienia polskich składników.
